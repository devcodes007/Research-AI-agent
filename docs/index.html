    The agent

    How the research was done

    Code does retrieval and checking; the LLM only reads and classifies. That keeps cost at $0 on free tiers, works with any model, and stops the model from inventing evidence.

    1 Search3 web-search queries per app (keyless search; Composio's search tools were restricted for the free key).
    Code
    2 FetchRank official docs first, fetch pages safely, cache them.
    Code
    3 ExtractAn agent reads the pages and returns structured JSON with verbatim quotes (file handoff; any model or LLM API also works).
    Agent (Claude)
    4 GroundEvery quote is searched for in the cached page. No match, no credit.
    Code
    5 Blind recheckSecond pass: different queries, separate context, never shown pass 1. Plus Composio's toolkit catalog as an independent auth cross-check.
    Agent + Composio SDK
    6 AdjudicateOnly disputed fields, with both sides’ evidence; a change needs a verified quote.
    LLM + Code
    7 Human auditUnlabelled values judged against the docs; accuracy scored.

        Runnable

        Run the agent yourself

        Free: Composio Hobby plan (no card) and a free LLM key (Gemini, Groq, or local Ollama).

        pip install -r requirements.txt
cp .env.example .env        # add COMPOSIO_API_KEY and one LLM key
python -m atlas doctor      # 30-second check of keys, search, LLM
python -m atlas research --ids 1-5    # try 5 apps
python -m atlas research              # all 100, both passes
python -m atlas reconcile && python -m atlas patterns && python -m atlas build

        Swap models with one line: ATLAS_MODEL=groq/llama-3.3-70b-versatile (or ollama/…, openrouter/…, anthropic/…). The repo also has a GitHub Actions button (manual dispatch) that runs a chosen batch.
